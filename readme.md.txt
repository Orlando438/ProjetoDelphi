Este é um sistema simples de cadastro de produtos e controle de vendas, desenvolvido em **Delphi XE7+**, utilizando banco de dados **Firebird** e bibliotecas como `ACBrCEP` e `ReportBuilder`.

Como Usar >>
-Configure o banco de dados
-Crie o banco em .fdb usando os scripts acima
-Compile o projeto no Delphi
-Execute o sistema
-Configure no menu principal os dados de conexão e clique em salvar.

Funcionalidades disponíveis:
-Cadastro de produtos
-Registro de vendas com múltiplos produtos
-Consulta de CEP via botão de busca
-Visualização e exportação da venda em formato JSON
-Geração de relatório com o FortesReport

Criacao das tabelas:

-- Criação da tabela de produtos
CREATE TABLE PRODUTO (
  ID INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  NOME VARCHAR(100),
  PRECO NUMERIC(10,2)
);

-- Criação da tabela de vendas
CREATE TABLE VENDA (
  ID INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  DATA_VENDA DATE,
  NOME_CLIENTE VARCHAR(100),
  CEP VARCHAR(10),
  RUA VARCHAR(100),
  NUMERO VARCHAR(10),
  BAIRRO VARCHAR(50),
  CIDADE VARCHAR(50),
  ESTADO VARCHAR(2),
  VALOR_TOTAL NUMERIC(10,2)
);

-- Criação da tabela de itens da venda
CREATE TABLE VENDA_ITEM (
  ID INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  VENDA_ID INTEGER,
  PRODUTO_ID INTEGER,
  QUANTIDADE INTEGER,
  PRECO_UNITARIO NUMERIC(10,2),
  VALOR_TOTAL NUMERIC(10,2),
  FOREIGN KEY (VENDA_ID) REFERENCES VENDA(ID),
  FOREIGN KEY (PRODUTO_ID) REFERENCES PRODUTO(ID)
);

COMMIT;

CREATE GENERATOR GEN_VENDA_ID;
SET GENERATOR GEN_VENDA_ID TO 1

CREATE GENERATOR GEN_VENDAITEM_ID;
SET GENERATOR GEN_VENDAITEM_ID TO 1

CREATE GENERATOR GEN_PRODUTO_ID;
SET GENERATOR GEN_PRODUTO_ID TO 10
